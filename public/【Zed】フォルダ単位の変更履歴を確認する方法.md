## はじめに

Zed にはファイルの変更履歴（Git ログ）をグラフィカルに確認できる「History」機能があります。これまではファイル単体にしか使えませんでしたが、2026年4月30日にマージされた PR により、**フォルダやプロジェクトルートに対しても履歴を表示できる**ようになりました。

## 機能の説明

プロジェクトパネル（サイドバーのファイルツリー）でフォルダや任意のエントリを右クリックすると、コンテキストメニューに **「View History」** という項目が表示されます。これを選ぶと、そのフォルダ以下に影響したコミットの一覧がグラフ付きで表示されます。

以前は "View File History" という名前でファイル専用でしたが、今回の変更でフォルダ・プロジェクトルートにも対応し、メニュー名も **「View History」** に統一されました。

## 使い方

### フォルダの変更履歴を確認する

1. 左サイドバーのプロジェクトパネルを開く
2. 履歴を確認したいフォルダを右クリック
3. コンテキストメニューから **「View History」** を選択

すると、そのフォルダ配下のファイルに影響したコミット履歴がタブで開きます。

### プロジェクト全体の変更履歴を確認する

プロジェクトルート（一番上のフォルダ）を右クリックして「View History」を選ぶと、リポジトリ全体のコミット履歴（`git log` 相当）を確認できます。

### コマンドパレットから実行する

キーボード操作が好きな方はコマンドパレットからも起動できます。

```
Ctrl+Shift+P（macOS: Cmd+Shift+P）で開いた後、"file history" と入力
```

アクション名は `git::FileHistory` です。プロジェクトパネルにフォーカスがあるときにこのアクションを実行すると、選択中のエントリ（ファイル・フォルダいずれも）の履歴が表示されます。

## 表示内容の違い

| 対象 | グラフ列の表示 | 用途 |
|------|--------------|------|
| ファイル | 非表示 | 単一ファイルの変更追跡 |
| フォルダ | 非表示 | 特定モジュール・ディレクトリの変更追跡 |
| プロジェクトルート | 表示あり | リポジトリ全体の俯瞰 |

ファイルやフォルダを対象にした場合は Git グラフ列が省略され、コミット一覧がシンプルに表示されます。プロジェクトルートを対象にした場合は通常の Git Graph と同じく、ブランチの分岐・合流がグラフで可視化されます。
